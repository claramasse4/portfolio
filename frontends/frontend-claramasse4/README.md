# Frontend de @claramasse4

- **Technologie** : HTML, CSS et JavaScript natifs
- **Lancer** : depuis ce dossier, `python -m http.server 5500`
- **Backend** : `GET http://localhost:8000/personnes/clara-masse`
- **Comportement** : `app.js` tente de charger les liens depuis l’API et conserve les valeurs statiques en cas d’erreur
